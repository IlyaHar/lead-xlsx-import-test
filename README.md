# Импорт заявок из XLSX

Тестовое задание: веб-страница импортирует 100 000 строк из предоставленной Excel-книги в MySQL при стандартном `max_execution_time = 30` секунд.

## Запуск

```bash
cp .env.example .env
docker compose up --build -d
```

Откройте [http://localhost:8080](http://localhost:8080), выберите файл `База даних.xlsx` и нажмите «Импортировать».

Повторный импорт безопасен: `external_id` имеет уникальный индекс, а существующие заявки обновляются. Одновременно может выполняться только один импорт.

## Почему импорт укладывается в лимит

- XLSX читается последовательно через `XMLReader`; XML листа не загружается целиком в память.
- Запись выполняется одной транзакцией пакетами по 500 строк, то есть для 100 000 заявок требуется 200 `INSERT`-запросов.
- Для повторного запуска используется `INSERT ... ON DUPLICATE KEY UPDATE`.
- Индексы ограничены полями, которые нужны для типовых выборок.

Лимит 30 секунд задан в `docker/php/php.ini`. После импорта интерфейс показывает фактическое время и пиковое потребление памяти.

## Структура данных

DDL находится в [`database/schema.sql`](database/schema.sql). Таблица хранит все 15 колонок исходного файла и технические поля `id`, `imported_at`. Пустые ячейки сохраняются как `NULL`, даты Excel преобразуются в `DATETIME`, телефон хранится строкой.

## Проверка

```bash
php tests/LeadNormalizerTest.php
docker compose exec db mysql -ulead_user -plead_password lead_import \
  -e "SELECT COUNT(*) AS leads_count FROM leads;"
```

Ожидаемый результат после импорта предоставленного файла: `100000` строк.
